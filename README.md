# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository
2. Masuk ke folder project
3. Jalankan `composer install`
4. Atur konfigurasi database pada file `.env`
5. Jalankan `php artisan migrate`
6. Jalankan `php artisan serve`
